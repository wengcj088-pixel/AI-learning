## 一、机器学习基础概念

| 术语 | 人话解释 |
|---|---|
| **人工智能 (AI)** | 让机器做需要"智能"才能完成的事，比如识别图片、理解语言、下棋。 |
| **机器学习 (ML)** | AI 的一个分支：不靠人手写规则，而是让机器**从数据里自己找规律**。 |
| **深度学习 (DL)** | 机器学习的一个分支，用"深层神经网络"来学，特别擅长图像、语音、文本。 |
| **模型 (Model)** | 学出来的那套"规律"的载体。你给它输入，它给你输出。可以理解成一个"超级复杂的函数"。 |
| **训练 (Training)** | 给模型看大量带答案的数据，让它不断调整自己，直到预测得越来越准的过程。 |
| **推理 (Inference)** | 训练好之后，拿模型来**实际使用**（给它新输入、要它给答案）。 |
| **数据集 (Dataset)** | 用来训练/测试模型的一堆数据。通常分训练集、验证集、测试集。 |
| **特征 (Feature)** | 输入数据里被拿来做判断的"属性"。比如判断房价，面积、地段就是特征。 |
| **标签 (Label)** | 数据的"正确答案"。比如一张图的标签是"猫"。 |
| **监督学习** | 训练数据带标签（有答案），模型照着学。最常见。 |
| **无监督学习** | 训练数据没标签，模型自己找结构（比如聚类）。 |
| **强化学习 (RL)** | 通过"试错 + 奖励"来学，像训练宠物。AlphaGo、机器人控制常用。 |

## 二、模型训练相关

| 术语 | 人话解释 |
|---|---|
| **参数 (Parameters / Weights)** | 模型内部可调的数字。训练就是在不断调这些数字。"7B 模型"就是有 70 亿个参数。 |
| **损失函数 (Loss)** | 衡量模型"错得有多离谱"的一个数字。训练目标就是让它越来越小。 |
| **梯度 (Gradient)** | 损失对参数的"变化方向"。告诉模型"往哪调参数能让错误变小"。 |
| **反向传播 (Backpropagation)** | 计算梯度的核心算法，把误差从输出层一层层传回去。深度学习的基石。 |
| **梯度下降 (Gradient Descent)** | 顺着梯度方向一点点调参数，让损失下降。最基础的优化方法。 |
| **学习率 (Learning Rate)** | 每次调参数迈多大步子。太大会震荡，太小学得慢。 |
| **Epoch** | 把整个训练集完整过一遍叫一个 epoch。通常要跑很多个。 |
| **Batch** | 训练时一次喂给模型的一小撮数据。 |
| **过拟合 (Overfitting)** | 模型把训练数据"背下来了"，一遇到新数据就拉胯。 |
| **欠拟合 (Underfitting)** | 模型太弱，连训练数据的规律都没学会。 |
| **正则化 (Regularization)** | 防止过拟合的一系列手段（如 Dropout、权重衰减）。 |

## 三、神经网络与深度学习

| 术语 | 人话解释 |
|---|---|
| **神经元 (Neuron)** | 神经网络的最小单元：输入加权求和，再过一个激活函数。 |
| **激活函数** | 给神经元加"非线性"的开关（ReLU、Sigmoid 等），没它网络就只是线性叠加。 |
| **神经网络层 (Layer)** | 一堆神经元排成一层。多层叠起来就是"深度"网络。 |
| **前向传播 (Forward Pass)** | 数据从输入层流到输出层，得到预测结果的过程。 |
| **CNN (卷积神经网络)** | 擅长处理图像，用"卷积核"扫描局部特征。 |
| **RNN / LSTM** | 擅长处理序列（文本、时间序列），有"记忆"。已大部分被 Transformer 取代。 |
| **Embedding (嵌入)** | 把离散的东西（词、物品）变成一串数字向量，让机器能计算"语义距离"。 |
| **张量 (Tensor)** | 多维数组。深度学习里所有数据（图片、文本）都表示成张量。 |

## 四、大语言模型 (LLM) 核心

| 术语 | 人话解释 |
|---|---|
| **大语言模型 (LLM)** | 用海量文本训练出来的超大神经网络，能理解和生成语言。如 GPT、Claude、Llama。 |
| **Transformer** | 现代 LLM 的底层架构。核心是"注意力机制"，2017 年论文《Attention Is All You Need》提出。 |
| **注意力机制 (Attention)** | 让模型在处理一个词时，能"关注"到句子里所有相关的词，从而理解上下文。 |
| **Self-Attention (自注意力)** | 句子内部的词互相"看"对方，计算彼此相关性。Transformer 的核心。 |
| **Token** | 模型处理文本的最小单位，可能是一个词、半个词或一个字。"上下文 8k" = 能记住 8000 个 token。 |
| **Tokenizer (分词器)** | 把文本切成 token 的工具。 |
| **预训练 (Pre-training)** | 在海量通用文本上从头训练，让模型学会语言的基本规律。烧钱、耗时。 |
| **微调 (Fine-tuning)** | 在预训练模型基础上，用少量特定数据继续训练，让它擅长某个任务。 |
| **LoRA** | 一种高效微调方法，只训练少量额外参数，省显存、省钱。 |
| **上下文窗口 (Context Window)** | 模型一次能"看到"的最大 token 数。超了就会忘掉前面的。 |
| **温度 (Temperature)** | 控制生成的随机性。高 = 更有创意/发散，低 = 更确定/保守。 |
| **幻觉 (Hallucination)** | 模型一本正经地胡说八道，编造不存在的事实。 |

## 五、生成式 AI 应用层

| 术语 | 人话解释 |
|---|---|
| **生成式 AI (GenAI)** | 能"创造"新内容（文本、图片、代码）的 AI，区别于只做分类/预测的传统模型。 |
| **Prompt (提示词)** | 你给大模型的输入指令。写得好不好直接决定输出质量。 |
| **Prompt Engineering** | 设计和优化提示词的技巧，让模型输出更符合预期。 |
| **Few-shot / Zero-shot** | 给模型几个例子（few-shot）或不给例子（zero-shot）让它照做。 |
| **RAG (检索增强生成)** | 先从你的知识库里检索相关资料，再让大模型基于这些资料回答。解决"幻觉"和"不知道私有知识"。 |
| **向量数据库 (Vector DB)** | 专门存 Embedding 向量、支持"语义相似搜索"的数据库。RAG 的核心组件。如 Pinecone、Chroma、Milvus。 |
| **Agent (智能体)** | 能自己规划、调用工具、多步完成任务的 AI。不只是回答，还能"行动"。 |
| **Function Calling / Tool Use** | 让大模型能调用外部工具/API（查天气、算数、搜数据库）。 |
| **MCP (Model Context Protocol)** | 一种让 AI 应用标准化接入外部工具和数据源的协议。 |
| **Chain (链)** | 把多个 LLM 调用/工具串起来完成复杂任务，LangChain 因此得名。 |

## 六、工程与部署 (MLOps)

| 术语 | 人话解释 |
|---|---|
| **MLOps** | 把机器学习模型从"实验室"搬到"生产环境"并持续运维的一整套工程实践。 |
| **模型部署 (Deployment)** | 把训练好的模型包装成服务（API），让别人能实际调用。 |
| **推理服务 (Inference Serving)** | 专门负责跑模型推理、对外提供 API 的服务。 |
| **API** | 应用之间通信的接口。你的 AI 应用通常对外暴露一个 REST API。 |
| **容器化 / Docker** | 把应用和它的运行环境打包成一个"集装箱"，到哪都能一致运行。 |
| **CI/CD** | 持续集成/持续部署：代码一改就自动测试、自动上线。 |
| **模型监控 (Monitoring)** | 上线后持续盯着模型表现（延迟、准确率、数据漂移），出问题及时报警。 |
| **数据漂移 (Data Drift)** | 线上真实数据和训练时的数据分布变了，导致模型效果下降。 |
| **A/B 测试** | 同时上线两个版本，用真实流量对比哪个更好。 |
| **模型量化 (Quantization)** | 把模型参数从高精度压缩到低精度，让它更小更快，适合部署。 |
| **GPU / 显存 (VRAM)** | 训练和推理大模型主要靠 GPU，显存大小决定能跑多大的模型。 |
