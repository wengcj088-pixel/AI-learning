## 二、分领域细图

### 🔹 数学基础（不需要全精通，够用即可）

```
线性代数 ──▶ 向量/矩阵运算 ──▶ Embedding 理解
   │
概率统计 ──▶ 分布/期望/贝叶斯 ──▶ 损失函数理解
   │
微积分   ──▶ 导数/偏导/链式法则 ──▶ 反向传播理解
```

> 💡 **零基础提示**：不用先啃完数学再学 AI。跟着 `ML-For-Beginners` 和 Karpathy 的课，用到哪补哪，效率最高。

### 🔹 从神经网络到 Transformer

```
神经元 ──▶ 多层网络 ──▶ 前向传播 ──▶ 损失计算
                                      │
反向传播 ◀── 梯度 ◀── 链式法则 ◀──────┘
   │
   ▼
梯度下降 ──▶ 优化器(Adam) ──▶ 训练循环
   │
   ▼
Embedding ──▶ 自注意力 ──▶ 多头注意力 ──▶ Transformer Block ──▶ GPT
```

### 🔹 从 LLM 到应用

```
LLM(预训练模型)
   │
   ├──▶ Prompt 工程 ──────────▶ 直接对话应用
   │
   ├──▶ RAG ──▶ Embedding + 向量库 ──▶ 私有知识问答
   │
   ├──▶ 微调(LoRA) ───────────▶ 领域专用模型
   │
   └──▶ Agent ──▶ 工具调用 + 规划 ──▶ 自动化任务
```

### 🔹 部署闭环

```
训练好的模型/应用
   │
   ▼
封装成 API (FastAPI/Flask)
   │
   ▼
容器化 (Docker)
   │
   ▼
部署 (云服务器/Serverless/K8s)
   │
   ▼
监控 + 日志 + 报警
   │
   ▼
数据反馈 ──▶ 迭代优化 ──▶ (回到训练)  ← 真正的闭环
```

## 三、学习顺序建议（对应本仓库五阶段）

| 先学 | 再学 | 原因 |
|---|---|---|
| Python 编程 | 机器学习 | 不会写代码没法动手 |
| 机器学习基础 | 神经网络 | 先懂"从数据学规律"这个大思想 |
| 反向传播 | Transformer | 不懂梯度就不懂模型怎么训练出来的 |
| Transformer | LLM 应用 | 懂原理才知道 Prompt/RAG 为什么这样设计 |
| Prompt 工程 | RAG / Agent | 先会基础调用，再做复杂系统 |
| 会做应用 | 部署上线 | 有东西可部署，才谈得上 MLOps |

## 四、常见"跳步"陷阱

- ❌ **不学原理直接做应用** → 遇到 bug 只能瞎试，成长天花板很低。
- ❌ **数学全啃完才动手** → 效率极低，容易劝退。用到再补。
- ❌ **只训练不部署** → 模型永远躺在 notebook 里，不算真正会 AI。
- ✅ **正确姿势**：每个阶段动手做一个能跑的小项目，边做边补短板。
