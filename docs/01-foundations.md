## 📖 核心概念

### 机器学习到底在干什么？

传统编程：`人写规则 + 数据 → 结果`
机器学习：`数据 + 结果 → 机器自己找出规则（模型）`

举例：判断邮件是不是垃圾邮件。
- 传统做法：人手写一堆规则（含"中奖"就是垃圾…），累且不准。
- ML 做法：喂给机器 10 万封"已标注是否垃圾"的邮件，它自己学出规律。

### 三类机器学习

| 类型 | 数据 | 例子 |
|---|---|---|
| 监督学习 | 带标签（有答案） | 房价预测、图片分类 |
| 无监督学习 | 无标签 | 用户分群、异常检测 |
| 强化学习 | 靠奖励信号 | 游戏 AI、机器人 |

### 一个模型的生命周期

```
准备数据 → 选模型 → 训练 → 评估 → 调优 → 使用(推理)
```

### 1. 一个 ML 项目的标准 7 步（务必背下来）

任何机器学习任务，都逃不出这 7 步。这是 ML-For-Beginners 反复强调的主线：

```
① 定义问题   →  这是分类？回归？还是聚类？要预测什么？
② 收集数据   →  数据从哪来，够不够，质量如何
③ 清洗数据   →  处理缺失值、异常值、重复值、格式统一
④ 特征工程   →  挑选/构造对预测有用的特征（决定成败的一步）
⑤ 划分数据   →  训练集(70%) / 验证集(15%) / 测试集(15%)
⑥ 训练+调优  →  选模型 → 训练 → 看指标 → 调参数 → 再训练
⑦ 评估+部署  →  在"没见过的"测试集上验证，达标才上线
```

> **为什么要分训练/测试集？** 用做过的题考自己一定 100 分，但那是背答案。测试集就是"没做过的新题"，只有在它上面表现好，才说明模型真学会了规律，而不是死记硬背（这叫**过拟合**）。

### 2. 五个必须建立直觉的经典算法

课程里讲了一堆算法，但零基础阶段你只要建立起这 5 个的**直觉**（不用会推导公式）：

| 算法 | 一句话直觉 | 用来干什么 |
|---|---|---|
| **线性回归** | 找一条直线/平面最好地拟合数据 | 预测连续数值（房价、销量） |
| **逻辑回归** | 线性回归 + 一个"压成 0~1 概率"的开关 | 二分类（是/否、垃圾邮件与否） |
| **决策树** | 像玩"20 个问题"游戏，一层层问 yes/no 分流 | 分类/回归，可解释性强 |
| **随机森林** | 让几百棵决策树投票，少数服从多数 | 又准又稳，实战常用首选 |
| **K-近邻(KNN)** | "物以类聚"——看你身边最近的 K 个邻居是啥类 | 简单分类，理解"相似度"概念 |

### 3. 怎么判断模型好不好？评估指标

**分类任务**（判断类别）：

- **准确率 (Accuracy)**：预测对的比例。⚠️ 陷阱：如果 99% 邮件不是垃圾，模型全猜"不是"也有 99% 准确率，但毫无用处。
- **精确率 (Precision)**：模型说"是"的里面，真的有多少是对的。（宁可放过，不可错杀 → 看这个）
- **召回率 (Recall)**：所有真正的"是"，模型抓住了多少。（宁可错杀，不可放过 → 看这个）
- **F1 分数**：精确率和召回率的调和平均，两者兼顾时看它。

**回归任务**（预测数值）：

- **MAE（平均绝对误差）**：预测值和真实值平均差多少，直观。
- **RMSE（均方根误差）**：对大误差惩罚更重，最常用。
- **R²**：模型解释了数据里多少比例的波动，越接近 1 越好。

### 4. 过拟合 vs 欠拟合（新手最容易栽的坑）

```
欠拟合：模型太简单，训练集都学不好      → 加特征/换复杂模型
刚刚好：训练集好，测试集也好            → 目标状态 ✅
过拟合：训练集近乎满分，测试集一塌糊涂  → 数据不够/模型太复杂/背答案了
```

**治过拟合的常用手段**：增加数据、简化模型、正则化（给模型加"别太激进"的约束）、交叉验证。

1. **环境搭建**：安装 Python + Jupyter Notebook（或直接用 Google Colab，免安装）
2. **跟做 ML-For-Beginners 前 4 课**：了解回归、分类
3. **完成一个分类项目**：比如用鸢尾花数据集（Iris）训练一个能区分花种类的模型
   - 加载数据 → 划分训练/测试集 → 训练 → 看准确率
4. **✅ 交付物**：一个能跑的 `.ipynb`，输入花的特征，输出预测的花种类，并打印准确率

```python
# 你的第一个 ML 模型大概长这样（心里有个数）
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

X, y = load_iris(return_X_y=True)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = DecisionTreeClassifier()
model.fit(X_train, y_train)              # 训练
print("准确率:", model.score(X_test, y_test))  # 评估
```
